Design decisions needing approval at G1b

  1. Visual system: Soft Modern / Minimal Utility — tokens in SCREEN_SPECS.md. Small text on the page background uses a slightly darker muted colour (#55637A) than the requested #64748B, which is 4.4:1 on #F5F7FB (below AA); #64748B stays for icons and text on white.
  2. Tabs: bottom navigation with icon + label and a filled pill for the active tab, on mobile and desktop.
  3. Disabled actions: shown muted with no explanatory message; the empty preview and error panels carry the explanation.
  4. Notifications: inline bars under the header (never floating over navigation or buttons); status uses icon shape + text, not colour alone.
  5. Saved card: Open is the primary button in the card header; Rename / Download / Share / Delete are a row of icon-over-label text actions (Share absent when unsupported).
  6. Limits: Medium 2,331 bytes, Low 2,953 bytes (standard capacities, to be asserted by CI — not yet run).
  7. Unchanged from v1: live generation, “Open” loads text into Generate, saving an edit creates a new item, install hint only when offered.
