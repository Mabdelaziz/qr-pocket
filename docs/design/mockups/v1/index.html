Design decisions needing approval at G1b

  1. Tabs: bottom tab bar on mobile; on desktop keep it at the bottom of the centred 560 px column (simple, one layout).
  2. Too-long at Medium: Medium limit is 2,331 bytes (QR v40-M, byte mode); Low is 2,953. Figures are standard capacity values and will be asserted by CI tests — not yet executed.
  3. Live generation (no Generate button): preview updates as you type (150 ms debounce).
  4. Visual style: white surface, blue primary (#0B57D0), red only for destructive actions, system fonts, 48 px targets, 3 px focus ring. Light theme only.
  5. Saved card: five visible text buttons (Open, Rename, Download, Share, Delete); Share omitted per card when unsupported.
  6. Open on a saved item loads its text into Generate; saving changed text creates a new item (no overwrite).
  7. Install hint only when the browser offers it; no iOS instructions in MVP.
